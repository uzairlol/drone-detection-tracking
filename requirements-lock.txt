# ---------------------------------------------------------------------------
# anti-uav - known-good dependency snapshot
# ---------------------------------------------------------------------------
# Generated from a working environment on Windows / Python 3.11 / CUDA 12.6, and
# verified against the test suite (213 tests), `ruff`, `mypy` and
# `anti-uav verify-env`. It is a snapshot, not a constraint set: it pins the
# resolution that is known to work, so a new machine reproduces it instead of
# re-resolving against whatever PyPI serves tomorrow.
#
# Install with:
#     pip install -r requirements-lock.txt
#     pip install -e .                 # the project itself, unpinned on purpose
#
# scripts\setup_env.ps1 does both, in the right order:
#     .\scripts\setup_env.ps1 -Profile pascal -UseLockFile -UpgradeTorch
#
# ---------------------------------------------------------------------------
# torch and torchvision are deliberately ABSENT
# ---------------------------------------------------------------------------
# One lock cannot pin five GPU tiers. And a wrong torch build does not fail at
# install time - it imports cleanly, reports CUDA as available, and then dies
# hours into training with "no kernel image is available for execution on the
# device". So torch is installed per machine, and `anti-uav verify-env` checks
# the result against the GPU's actual compute capability before you spend any
# GPU hours.
#
#   profile    GPU              needs           index
#   --------   --------------   ------------    ------------------------------------
#   pascal     GTX 1070 sm_61   torch 2.6 cu126  https://download.pytorch.org/whl/cu126
#   volta      V100 sm_70       torch 2.x cu126  https://download.pytorch.org/whl/cu126
#   turing     T4 sm_75         torch 2.x cu126  https://download.pytorch.org/whl/cu126
#   ampere     RTX 3090 sm_86   torch 2.x cu124  https://download.pytorch.org/whl/cu124
#   ada        RTX 4090 sm_89   torch 2.x cu128  https://download.pytorch.org/whl/cu128
#   blackwell  RTX 5090 sm_120  torch 2.x cu128  https://download.pytorch.org/whl/cu128
#   cpu        none             any              (default PyPI wheel)
#
# CUDA 12.8 removed Maxwell and Pascal outright, which is why pascal needs an
# older torch AND an older CUDA line, not just an older torch. 12.6 is the
# newest runtime that still carries sm_61 kernels. CUDA 13.x removed Volta too,
# so volta must stay on a 12.x line.
#
# --- PLATFORM SCOPE: Windows / cp311 only -------------------------------------
# The snapshot below was taken on Windows and verified only there. Three of its
# pins do not transfer to Linux and will FAIL or downgrade a Kaggle/Colab image:
#
#   lapx 0.10.0   ships manylinux AND win_amd64 wheels, so this one is fine.
#                 (The Windows-only spelling that trips people up is `lap`, not
#                 `lapx` - `lap` is Windows-only, `lapx` is the portable one.)
#   numpy         pinned to whatever the Windows box resolved. Re-pinning numpy
#                 against Kaggle's preinstalled torch is a reliable way to break
#                 CUDA; let the image keep its own numpy.
#   opencv-python Kaggle images ship `opencv-python-headless`. Installing the
#                 GUI build on top shadows it and can break `import cv2` for
#                 missing GUI system libraries.
#
# So: do NOT install this file on Kaggle. Install the project with its extras
# and let the image's torch/numpy/opencv stand:
#
#     uv pip install --system -e ".[train]"
#
# notebooks/kaggle_dvb.ipynb is written to do exactly that.
#
# If you have a local wheel - this repo's Pascal box uses
# D:\wheels\torch-<version>+cu126-cp311-cp311-win_amd64.whl - install it with
#     pip install <path-to-wheel>
# rather than from an index. A local wheel is how a cu126 build survives on a
# card whose driver predates that runtime.
#
# No hashes are recorded. Hash pinning needs a network round-trip per artifact
# and breaks the moment a mirror rotates a file; version pins plus `verify-env`
# are the cheaper guarantee.
#
# Regenerate after an intentional upgrade:
#     pip install -e ".[all]"
#     pip freeze --all        # then filter out pip, torch, torchvision, anti-uav
# ---------------------------------------------------------------------------
